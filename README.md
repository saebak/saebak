# Hi there, I'm Backend Developer 👋

Java/Kotlin과 Spring Boot를 기반으로 백엔드 서비스를 개발하고 있습니다.

서비스 구축부터 운영, 레거시 시스템 고도화까지 다양한 환경에서 개발을 경험해 왔으며,
비즈니스 요구사항을 안정적인 구조와 데이터 모델로 구현하는 것에 관심이 있습니다.

최근에는 AI 개발 도구를 실제 개발 과정에 활용하고, 반복적인 개발 업무를 자동화하는 방법도 함께 고민하고 있습니다.
